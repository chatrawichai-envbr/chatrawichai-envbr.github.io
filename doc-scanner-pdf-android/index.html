สแกนเอกสาร PDF — แอป Android

ถ่ายภาพหรือเลือกรูปเอกสาร ครอปตามขอบกระดาษ ลบเงา ปรับให้คมชัด แปลงข้อความ (OCR ไทย + อังกฤษ) และสร้าง PDF ที่ค้นหาข้อความได้ — ทำงานในเครื่องทั้งหมด ไม่ต้องใช้อินเทอร์เน็ต สำหรับมือถือและแท็บเล็ต Android 8.0 ขึ้นไป

  • ดาวน์โหลด APK รุ่น 1.0.18 doc-scanner-pdf-1.0.18.apk · 10.7 MB

ติดตั้ง

  1. กดดาวน์โหลดบนมือถือหรือแท็บเล็ต แล้วเปิดไฟล์ที่ดาวน์โหลด
  2. ครั้งแรก Android จะให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์ที่ใช้ดาวน์โหลด
  3. เปิดแอป สแกนเอกสาร PDF — ครั้งแรกที่ใช้กล้องในแอป Android จะถามสิทธิ์กล้อง

อัปเดต: ดาวน์โหลดรุ่นใหม่จากหน้านี้แล้วติดตั้งทับได้เลย (ทุกรุ่นเซ็นด้วยกุญแจเดียวกัน)
