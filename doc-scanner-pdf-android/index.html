สแกนเอกสาร PDF — แอป Android

ถ่ายภาพหรือเลือกรูปเอกสาร ครอปตามขอบกระดาษ ลบเงา ปรับให้คมชัด แปลงข้อความ (OCR ไทย + อังกฤษ) และสร้าง PDF ที่ค้นหาข้อความได้ — ทำงานในเครื่องทั้งหมด ไม่ต้องใช้อินเทอร์เน็ต สำหรับมือถือและแท็บเล็ต Android 8.0 ขึ้นไป

  • ดาวน์โหลด APK รุ่น 1.0.20 doc-scanner-pdf-1.0.20.apk · 11.9 MB

ติดตั้ง

  1. กดดาวน์โหลดบนมือถือหรือแท็บเล็ต แล้วเปิดไฟล์ที่ดาวน์โหลด
  2. ครั้งแรก Android จะให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์ที่ใช้ดาวน์โหลด
  3. เปิดแอป สแกนเอกสาร PDF — ครั้งแรกที่ใช้กล้องในแอป Android จะถามสิทธิ์กล้อง

อัปเดต: ดาวน์โหลดรุ่นใหม่จากหน้านี้แล้วติดตั้งทับได้เลย (ทุกรุ่นเซ็นด้วยกุญแจเดียวกัน)

มีอะไรใหม่ในรุ่น 1.0.20

  • แอปภาษาอังกฤษ (English) — ทุกหน้าจอเป็นภาษาไทยหรืออังกฤษตามภาษาของเครื่อง (ตั้งเครื่องเป็นภาษาไทย = ไทย) และเปลี่ยนได้ทุกเมื่อด้วยปุ่มรูปลูกโลกมุมขวาบนของหน้าแรก (จำค่าไว้) — ข้อความของแอปเอง (แจ้งเตือน, ชื่อแอป, ข้อผิดพลาดการบันทึก/แชร์) เปลี่ยนตามด้วย ชื่อแอปบนหน้าจอเครื่องเป็น "Doc Scanner PDF" เมื่อเครื่องเป็นภาษาอังกฤษ
  • เปิดแอปแล้วเห็นภาษาที่ถูกต้องทันที (ไม่มีภาษาไทยแวบก่อนเป็นภาษาอังกฤษ)
  • แอนิเมชันทั้งแอป — เปลี่ยนหน้าจอ เปิดหน้าต่าง ข้อความแจ้งเตือน และเพิ่ม/ย้าย/ลบหน้าแบบนุ่มนวล สั้นและไม่ต้องรอ ปิดเองเมื่อเครื่องเปิด "นำภาพเคลื่อนไหวออก" (ลดการเคลื่อนไหว)
  • ปุ่ม "สร้าง PDF" แสดงจำนวนหน้าบรรทัดที่สอง, ชื่อแอปที่หัวหน้าแรกอยู่บรรทัดเดียวบนจอแคบ
  • ไม่ส่งสถิติการใช้งานของตัวแสดงหน้าเว็บ (Android System WebView) ไปที่ Google — แอปไม่เก็บและไม่ส่งข้อมูลใด ๆ ออกจากเครื่อง; หน้าดาวน์โหลดมี นโยบายความเป็นส่วนตัว (ไทย/อังกฤษ) ที่ privacy.html
